# LuCI Wi-Fi Import (luci-app-wifi-import)

Кастомный плагин для веб-интерфейса OpenWrt (LuCI), спроектированный для **быстрого пакетного развертывания Wi-Fi сетей** методом копирования текстового списка. 

---

## Возможности и элементы управления

Панель управления интегрирована в раздел **Сеть (Network) -> Импорт Wi-Fi** и работает полностью в браузере (Client-Side) через официальный LuCI UCI API.

1. **Пароль Wi-Fi (Поле ввода):** Задает мастер-пароль для всех создаваемых точек (по умолчанию: `88888888`).
2. **Очистить предыдущий импорт (Чекбокс):** 
   - **Включено (по умолчанию):** Автоматически находит и удаляет только те Wi-Fi сети, которые были созданы этим плагином ранее. Ваши основные домашние сети и настройки интернета не будут затронуты.
   - **Выключено (Режим добавления):** Переводит плагин в режим добавления. Новые точки из списка будут дописаны в конец текущей конфигурации беспроводной сети без удаления старых данных.
3. **Диапазон для импорта (Выпадающий список):**
   - `2.4 and 5 GHz` — импортирует весь список сетей целиком (по умолчанию).
   - `2.4 GHz` — фильтрует список и поднимает только точки 2.4 ГГц.
   - `5 GHz` — фильтрует список и поднимает только точки 5.0 ГГц (ищет маркеры `5G`, `5g` или `5GHz` в SSID).
4. **Список MAC-адресов (Текстовая область):** Удобное поле ввода для прямой вставки данных.

## Быстрая установка одной командой

Для установки плагина подключитесь к вашему роутеру по **SSH** и выполните следующую команду:

```bash

wget -qO- https://raw.githubusercontent.com/mazyakovai/luci-app-wifi-import/main/install.sh | sh && /etc/init.d/uhttpd restart

```

*После установки обязательно обновите страницу LuCI в браузере (F5). Плагин появится в выпадающем меню **Сеть (Network) -> Импорт Wi-Fi**.*

---

## Формат импортируемых данных

Cкопируйте строки вашего списка в формате `mac,ssid` и вставьте их в текстовое поле формы. 

**Пример списка:**
```text
84:00:2D:8E:42:31,XfinityWiFi_Home_1
00:22:15:AF:92:22,XfinityWiFi_Home_11_5G
```
